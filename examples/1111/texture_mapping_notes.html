TEXTURE MAPPING 
In a web browser, you cannot
load textures from a local  
file, for security reasons. 

You must run a local server,
then launch your scene as:  


https://localhost:8000

I use a python server for textures:


https://python.org/downloads

To start the server in a terminal window:


python3 -m http.server  

or  

python3 -m http.server &
ANTIALIASING BY MIPMAPPING 
The texture source 
image is converted 
into a power-of-two
pyramid of images. 

When the GPU samples the
image, it interpolates
along 3 dimensions:


u: horizontally  
v: vertically    
s: between levels

RESTRICTION:

The width and height of your
texture source image both
need to be powers of 2.
