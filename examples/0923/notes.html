In this document I describe the math to ray trace to an axis-aligned cube.

First, let's talk about ray tracing to the following half-space: 

   ax + by + cz + d < 0
That half-space can be described as a vector of length 4: 
   P = [a,b,c,d]

Given ray V + tW, where V is the point in space: 

   Vx
   Vy
   Vz
   1
and W is the direction vector: 
   Wx
   Wy
   Wz
   0
the value of t ofgwhere the ray hits the plane of P is: 
   t = - V•P / W•P
Let's assume that a cube we want to render is centered at point C and has half-width r.

The half-space which defines being to the right of the left edge of the cube is given by: 

   x > Cx - r
Let's convert this into standard form: 
   -x < -Cx + r
→
   -x + Cx - r < 0
→
   Pxlo = [ -1, 0, 0, Cx - r ]
Now let's do the same for the half-space which defines being to the left of the right edge of the cube: 
   x < Cx + r
→
   x - Cx - r < 0
→
   Pxhi = [ 1, 0, 0, -Cx - r ]
If we apply the same logic to y and z that we just applied to x, we get a total of 6 half-spaces: 
   Pxlo = [ -1,  0,  0,  Cx - r ]
   Pxhi = [  1,  0,  0, -Cx - r ]
   Pylo = [  0, -1,  0,  Cy - r ]
   Pyhi = [  0,  1,  0, -Cy - r ]
   Pzlo = [  0,  0, -1,  Cz - r ]
   Pzhi = [  0,  0,  1, -Cz - r ]
To ray trace to a cube, you need to ray trace to all 6 of these half-spaces.

Each half-space might either be one that the ray enters into, or one that the ray emerges out of.

If W•Pxyz<0 then this is a half-space that the ray enters into.

Conversely, if W•Pxyz>0 then this is a half-space that the ray emerges out of.

To find where the ray enters the cube, you need to take the maximum t0 of the values of t for the half-spaces that the ray enters into.

To find where the ray emerges out of the cube, you need to take the minimum t1 of the values of t for the half-spaces that the ray emerges out of.

If t0 < t1 then the ray has hit the cube. Otherwise the ray has missed the cube, which you can indicate by returning -1.

You also need to compute the surface normal at the face where the ray enters the cube. This is just given by the first three numbers of the associated P.

For example, if the ray entered the cube from the cube's left side (via Pxlo), then the surface normal is [-1,0,0].

When coding this in your fragment shader, and replacing function raySphere by function rayCube, you might find it easier to compute both the value of t and also the surface normal within rayCube.

So, for example, your call to rayCube might look like this: 

   vec4 rayCube(vec3 V, vec3 W, vec4 C)
where C.xyz specifies the cube's center, and C.w specifies the cube's half-width.

Your rayCube function can then return both the surface normal N and the value of t, with N being the first three numbers in the returned vec4 and t being the fourth number.

If you use this approach, then you can return vec4(0.,0.,0.,-1.) whenever the ray misses the cube.

Also remember to use the returned surface normal in your shading calculations.
